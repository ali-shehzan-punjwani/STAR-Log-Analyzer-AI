
# STAR Log Analyzer – AI & Machine Learning SOC System

## Overview
STAR Log Analyzer is an AI-powered cybersecurity log analysis system developed using Python and Streamlit. The system combines rule-based threat detection with Machine Learning anomaly detection using the Isolation Forest algorithm.

It simulates a real-world Security Operations Center (SOC) environment by analyzing network logs, detecting suspicious behavior, and classifying IP addresses based on risk levels.

---

## Features
- Rule-based cyber threat detection
- Machine Learning anomaly detection
- Brute-force attack detection
- Bot activity detection
- Suspicious login analysis
- Risk scoring system
- Real-time Streamlit dashboard
- IP-wise behavioral analysis

---

## Technologies Used
- Python
- Streamlit
- Pandas
- Scikit-learn
- Isolation Forest Algorithm

---

## Threats Detected
- Brute-force attacks
- High traffic anomalies
- Suspicious login behavior
- Unknown IP activity
- Bot-like rapid requests
